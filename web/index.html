Misje i wyniki

Uruchomiony profil udostępnia parowanie i status. Nie udostępnia API wykonywania misji. Brak odczytanych misji i receipts; nie pokazujemy przykładowych zadań jako wykonanych.

Critical · kontrola człowieka

TLS, podpisy, wygaśnięcie i odwołanie pozostają egzekwowane przez istniejący Core. Parowanie nie daje uprawnień WRITE, EXEC ani dostępu do płatnych modeli.

Repozytoria · GitHub

Ten profil nie udostępnia sterowania repozytoriami. Nie wykonano GitHub WRITE, commitu, push ani PR. Dowody repozytorium pojawią się dopiero przez obsługiwany kontrakt Core.

Szczegóły misji

Nie odczytano misji w tym profilu. Plan, testy, pliki i receipt wymagają rzeczywistych danych Core. STOP misji nie jest dostępny bez właściwego aktywnego zadania.

Odczyty i historia

Widok urządzeń pokazuje ostatni odczyt lokalnego rejestru Core. Liczba sesji nie jest dowodem aktualnego statusu online Androida. Nie załadowano pełnej historii audytu.

Dostawcy modeli

Profil parowania nie uruchamia modelu. Muse LIVE i lokalne LLM pozostają niedostępne w tym widoku; nie ma tu kluczy API ani przełącznika pozorującego ich aktywację.

Wormhole · odzyskiwanie

Na Androidzie wybierz Połącz ponownie lub Odśwież podpisany stan. Zapisane zatwierdzenie urządzenia pozostaje w Core. Nowy QR jest potrzebny dopiero, gdy rzeczywisty stan zaufania tego wymaga. Nie ponawiaj niepewnego żądania automatycznie.

Ustawienia i zaufanie

Sesja panelu wymaga rzeczywistej autoryzacji lokalnego operatora. Po jej wygaśnięciu otwórz panel ponownie z Linuxa. Zablokuj panel usuwa jego uprawnienie z pamięci; odwołanie urządzenia odbywa się przy konkretnym wpisie na stronie Urządzenia.
