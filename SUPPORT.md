# Support

## Questions and usage help

Use GitHub Issues for reproducible bugs, feature requests, and documentation problems. Before opening a new issue, search existing issues and repository documentation.

Include:

- AIOA version or commit;
- Python version and operating system;
- exact command or workflow;
- expected and observed behavior;
- minimal logs with secrets and personal data removed.

## Security

Do not use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md) and GitHub Private Vulnerability Reporting.

## Project scope

The repository is maintained as an open-source research and engineering runtime. Support is best-effort; competition-specific, archived, and historical branches may not receive fixes independent of the current default branch.
