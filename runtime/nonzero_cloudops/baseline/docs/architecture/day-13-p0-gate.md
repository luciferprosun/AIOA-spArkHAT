# Day 13 — Executable P0 Proof Gate

The canonical Day 13 gate is [`scripts/run_p0_gate.py`](../../scripts/run_p0_gate.py). It is verification code, not runtime authority: `CURRENT_TOOL_NAMES`, `FINAL_TOOL_CAP`, the typed authority contracts, and `DefaultDenyToolPolicy` remain authoritative while the agent is running. The gate performs no AWS operation. It resolves source symbols, validates deterministic static invariants, and executes exact pytest nodes with a temporary JUnit report. A missing or renamed source/test, failed collection, failure, error, or any skipped required proof makes the runner exit non-zero.

Run the full proof with:

```bash
.venv/bin/python scripts/run_p0_gate.py
```

Use `--json` for timing-free machine output. `--validate-only` checks the matrix, source anchors, node definitions, topology, mutation surface, tracked-file secret patterns, and prior-art integrity without executing pytest. Neither mode prints subprocess output, environment values, temporary paths, or secret candidates.

## Direct gaps closed in K1

The named gate exposed proof gaps that a total suite count could not show. K1 therefore adds focused tests for missing/mismatched checkpoint evidence, a missing durable proposal, cross-run/cross-proposal approval substitution, changed decision-nonce replay, each positive execution opt-in independently disabled, and terminal token-budget exhaustion. `load_execution_prerequisites` now requires the approved checkpoint's `build_remediation_evidence` hash to equal the immutable proposal hash.

K2 extends P0-02, P0-06, and P0-14 with the independent AU-1 control: the model/tool schema cannot carry it, only exact `false` releases its veto, human Approval cannot override it, and fresh checks bracket both fake-tested stop boundaries. The final exact node lists remain in the executable runner.

The prior-art static proof preserves the pre-Armor commit as an ancestor, resolves the immutable Phase 1 tag, checks the four audit artifacts by exact Git blob, and rejects linked legacy content or forbidden legacy runtime import roots. This is an integrity boundary, not a claim that string scanning proves authorship; provenance remains supported by the existing forensic audit.
