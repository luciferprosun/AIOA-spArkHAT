# Day 12 — Safety Hardening

`DefaultDenyToolPolicy` is the central pre-dispatch boundary for the one Strands agent. It recognizes only the frozen five exact tool names. AUTO requests must use the exact one-field schema and the configured sandbox instance. The stop path accepts only a UUIDv7 proposal reference and can reach native confirmation only when durable run/proposal truth is exactly `AWAITING_APPROVAL`; dispatch after confirmation remains subject to the existing durable Approval, scope, precondition and idempotency controls. Verification accepts only the durable proposal target in a verification/recovery state. Unknown names, aliases, cross-run references, target substitution and extra fields are denied before a tool handler runs.

The policy never searches prompt prose for permission. User/model instructions, logs and evidence are data, so text claiming prior approval or requesting Terminate/Start/Reboot/Modify, IAM, SSM, shell, code, URLs, tag changes, credentials or unsafe stop options cannot create a capability. Dangerous entries exist only in the closed `NEVER_AUTONOMOUS` policy catalog; none is an executable tool. A denial produces a typed failure and append-only `POLICY_DENIED` or `MODEL_OUTPUT_REJECTED` event. The event retains run/trace/correlation, a safe branch code and a SHA-256 request hash, never the raw injection payload.

Strict malformed output receives at most two correction attempts through `SchemaCorrectionBudget`; schemas are never relaxed. Exhaustion closes the durable run as `MODEL_OUTPUT_INVALID`. `BoundedReadRetry` retries only recognized transient EC2/CloudWatch read failures, at most two attempts by default (three is the hard configuration ceiling). AccessDenied, validation, policy denial, durable conditional conflict and mutation/ambiguous-ACK operations are excluded. Existing verification polling remains separately bounded, and Day 11 reconciliation remains the only route for an unknown mutation outcome.

`BudgetCounters` now preserves finite turn, token and elapsed-time limits with backward-compatible defaults. Each investigation invocation conditionally advances the durable Run version and appends `BUDGET_UPDATED`; a Strands limit stop or elapsed-time exhaustion appends `BUDGET_EXHAUSTED` and persists the terminal state before any proposal/approval/execution path can begin. Model text cannot change these application-owned values.

The shared failure map keeps validation, policy, ambiguity, dependency, budget, execution, verification and recovery categories aligned with their durable workflow states. Unexpected boundary exceptions are converted to generic typed failures without retaining exception text. Day 12 adversarial and regression tests are deterministic and use only local fakes; no live AWS read or mutation was performed.
