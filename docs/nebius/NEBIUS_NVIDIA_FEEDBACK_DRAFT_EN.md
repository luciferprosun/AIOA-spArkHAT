# Tool feedback — factual draft

Nebius Token Factory provides a clear exact NVIDIA Nemotron catalog identifier and OpenAI-compatible request surface. We integrated it through the existing native ProviderPort rather than introducing another provider manager. Public model pricing supports conservative UTF-8 byte-plus-framing admission, but the bound is not proof of actual billed spend or redeemed credits.

Historical Lightning probes exposed incomplete completions at smaller/different output bounds. One later smoke completed with stop; the preserved analysis does not establish which changed parameter caused success. We retained failed evidence, strict stop admission, exact model checks and no fallback. New architecture output remains unverified until an accepted fresh bounded call and independent review.

Helpful improvements: consistent safe request/finish/usage metadata on failures, explicit catalog/price freshness, and guidance on reasoning-token versus visible-output budgets. We intentionally do not persist hidden reasoning or credentials. NVIDIA Nemotron is an optional proposer/critic, never an approval authority. Local fixtures improve reproducibility but are not measurements of model quality.

Onboarding/satisfaction ratings, comparison scores and future-use commitments require the operator's actual experience; none is invented. Review against exact receipts before using this text in submission.
