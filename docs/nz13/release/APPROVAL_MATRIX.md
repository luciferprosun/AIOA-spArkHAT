# Zgody właściciela

| Zgoda | Zakres odrębnego podpisu |
|---|---|
| GO_A | Kwalifikacja wydzielonego publishera, UID/GID i niezależnej kotwicy. |
| GO_B | Jedno CAS kontrolera po PASS_A. |
| GO_C | Odrębna próba Native C07/A7/A8 po PASS_B. |
| GO_PR | Jedna nowa gałąź i jeden draft PR po kwalifikacji dokładnego HEAD. |
| GO_MERGE | Jeden PR po odbiorze wymaganych checków i exact merge tree. |
| GO_ARCHIVE_REPO | Przeniesienie NonZero w stan archiwalny po zatwierdzeniu zależności, historii i odbiorze po merge. |

Wnioski w pakiecie odbiorczym definiują parametry i warunki odczytu. Wszystkie wymagają niezależnego podpisu właściciela.
