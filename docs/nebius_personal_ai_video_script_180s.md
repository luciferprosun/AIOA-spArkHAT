## Recording acceptance

- The full recording is no longer than 180 seconds; aim for 165.
- Provider and effect target modes remain visible and distinct.
- Prepare and Approve both show zero effects; execution is a separate click.
- Show the receipt digest, independent readback, restart reconciliation and
  replay barrier before closing.
- Do not describe `ZERO_WRITE` as a Verified Delta, HAT retrieval as learning,
  CPL agreement as proof, or a fixture as live NVIDIA/Serverless execution.
- If a live receipt is mentioned, quote only the final manifest's actual
  result. A failed or blocked live inference is a limitation, not a success.
