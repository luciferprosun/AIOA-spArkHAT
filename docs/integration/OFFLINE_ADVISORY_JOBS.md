# Governor-owned offline advisory jobs

PRV LOCAL/OFFLINE scope: immutable JobEnvelope binds the existing ProviderRequest digest, exact Nebius/NVIDIA model, owner scope, native response schema, deadline, money/risk bounds. Prompt/provider payload is never stored in a job record. This is a typed offline lifecycle, not a cloud dispatcher, provider manager, human authority, or running worker.

CoreDualGovernor owns the methods. Its original policy, namespace and state shape are unchanged; pure reservation/dispatch/UNKNOWN/settle helpers are shared by the original methods and job transitions. An explicit admitted start_epoch is required before submission; constructors never initialize an epoch. Native OPERATION snapshots, audit, outbox and the injected serializable TransactionRunner remain the only persistence/coordination mechanism. Job claim and paired reservation, START and accounting marker, result and pessimistic settlement each commit together. Every changed job transition checkpoints the shared governor clock atomically, including lease renewal. READ does not sample the mutation clock and remains available on clock failure. Inputs/clocks and immutable provider response snapshots are prepared before retry callbacks.

Lifecycle: QUEUED -> CLAIMED -> STARTED -> DONE, or STARTED -> UNKNOWN. Each job has a monotonic local fence, host worker identity and bounded lease. Explicit admitted MANAGE takeover after lease expiry increments the fence. An undispatched reservation can transfer to the current governor epoch without refund/extra charge; previously STARTED work is UNKNOWN/reconciliation-only and retains full exposure. Stale workers cannot begin or publish a result. Other tasks are not fenced by a per-task takeover. Global governor epoch remains separate from task fence.

Only a newly acknowledged START yields fixture_step_now. Lost ACK, redelivery and process reconstruction never yield a second synthetic step. Expiry during durable START keeps its replay barrier and grants no step. DONE means advisory request bookkeeping completed, UNVERIFIED/NONE; it is not effect verification or approval. Native response shape/model/request identity and ADVISORY_ONLY are checked; raw responses remain outside the metadata store.

ASM/OPEN: host owns worker identity/Core composition and supplies truthful native transport receipts; opaque hashes do not prove model quality. This implementation does not run inference, construct a remote worker, publish a result, implement distributed target fencing, or guarantee external exactly-once. STARTED/UNKNOWN inspection and existing evidence review remain available; production provider readback/reconciliation wiring requires a later separately approved contract. Native history limits are shared; no pruning, namespace reset, silent restart or automatic retry occurs.

S1_LOCAL/S2_LOCAL refer only to synthetic local protocol cases. CLOUD_S1 = BLOCKED_APPROVAL; CLOUD_S2 = NOT_RUN_DEPENDS_S1. Historical HTTP 200 + exact model + one Nemotron architecture call had INCOMPLETE_COMPLETION; it is not live architecture content proof. Future real content validation must be separately bounded/authorized with exact model/cost/timeout, no fallback.
