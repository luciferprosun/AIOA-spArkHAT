# Native commit–select–reveal (local candidate)

One injected `CoreAdmission` and `TransactionRunner` own native OPERATION/AUDIT/OUTBOX records. `CoreVerifierBinding`, `VerificationInput`, `VerificationVerdict` and `VerifierReceipt` are reused. No evidence, memory, provider, authority or identity manager is created. Constructor and imports perform no provider call, storage write or random selection. N6/MCP and its running READ worker remain external.

The host first commits bounded, closed-schema native `ProviderResponse` content and exact request/producer/source/registry digests. Worker COMMIT cannot select verifiers: selection requires an admitted MANAGE principal and happens after durable commitment. Host RNG or explicit fixture picker executes outside retried transactions. The immutable stored selection survives restart and ACK loss. Workers cannot supply verifier IDs, seed or registry through the artifact. This is a typed native provider-output contract, not a generic opaque artifact transport replacement. Canonical UTF-8 bytes preserve legitimate NFD text; NFC/NFD changes after commitment cannot share its digest.

Reveal validates artifact, current admitted sources, owner/HAT, registry, expiry and selection before invoking a verifier. Mandatory local mechanics gates the selected advisory reviewers. Selected review receives the bounded worker claim and hashed context/scope refs, no canonical source text, private HAT payload, prompt, signer material or Core principal. Every result has authority NONE, execution_authority false and auto_retry false. SUPPORTED means these bounded checks passed, not human approval, architecture truth or effect verification. REVIEW_REQUIRED is not a permission. UNKNOWN retains its durable START liability and permits readback only.

START uses native `execute_once` replay ownership. Only the acknowledged new marker owner can run callbacks. A replay/CAS loser with an identical START binding reads receipt or returns UNKNOWN; it cannot run another checker. If concurrent trusted input timestamps differ, the losing exact START binding raises a closed IDEMPOTENCY_CONFLICT. A later explicit reveal reads the receipt or observes UNKNOWN, without rerunning callbacks; transparent concurrent readback is not promised for that case. Receipt replay checks the whole native audit chain, outbox binding, START/commit/selection/source edges, exact labels, verifier descriptors and original input digests. Missing/corrupt causal history fails closed. Lost receipt ACK reads the durable receipt without rerunning callbacks. The API creates no effect or provider dispatcher.

Limits: 4096-byte default artifact (32..8192 configurable), at most eight evidence refs and eight registered reviewers, 300-second maximum validity, one selected reviewer by default, at most 64 CSR tasks per owner-native domain. Native audit quota is shared and capped below 1024; capacity is checked before START leaving room for receipt at that moment. Other host workflows can consume remaining space later: that is UNKNOWN, not a guarantee of reserved global capacity or automatic redispatch. Clock rollback/expiry deny new checks.

Frozen native oracle definitions and type are hashed into registry identity, and the active definition is recomputed before commit/reveal/replay and after callbacks. Nested mutable values in a native frozen DTO cannot silently retain the cached pin. This is bounded host-state revalidation, not atomic distributed registry/code attestation. For opaque host callbacks, behavior/code/configuration must remain immutable within policy_version; host changes require a new version. This trust assumption is not production code attestation. Registered names, methods or families do not prove model independence. Selected advisory callbacks need not perform the same literal mechanics as the mandatory local checker. Effect authority still requires the separate existing human path.

`tests/nv08_canary.py` is an explicit offline SYNTHETIC_FIXTURE. Its seeded planted faults produce complete paired 00/01/10/11 counts, joint misses, covariance and correlation only when variance is positive. Callback errors are incomplete samples. Zero samples are UNKNOWN; constant all-miss vectors have covariance zero but are not independent. Shared method/family/object flags and independence_proven=false remain visible. No real model performance/generalization is asserted.

Current module is isolated from live entrypoints. Unified existing reviewer/demo wiring is a subsequent local convergence dependency; no second demo authority or Core is introduced here. Production signer custody, distributed selection fairness, remote code attestation and provider independence remain OPEN.
