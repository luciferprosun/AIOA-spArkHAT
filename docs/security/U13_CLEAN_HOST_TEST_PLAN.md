# Clean-host installation and lifecycle test plan

Status: PREPARATION_ONLY. No case below has been executed on an independent clean machine. This plan is not permission to install, provision a VM, download dependencies, contact a provider or publish an artifact. Execution requires an owner-authorized disposable target and a reviewed candidate, supplied offline. P1/P2/P3/D8 remain NOT_ACCEPTED.

Run the entire matrix independently on Ubuntu 24.04 amd64 and Linux Mint 22.x amd64. Record the exact OS point version/image digest, kernel, hardware, disk, memory, CPython version/SOABI and authenticated installed dependency versions. A fresh OS must contain no AIOA repository, Codex environment, developer Python packages, personal browser profile, private configuration, synthetic signer promoted as real, or ambient provider credentials. A container, extraction directory or developer laptop is not a clean OS result. No environment creation is part of the current U13 run.

For each case save an ID, start/end time, candidate SHA256, source commit/tree, exact actions and exit codes, expected versus observed behavior, sanitized stdout/stderr, file modes/hashes, package inventory before/after, network/effect observation and tester identity. Use PASS, FAIL, BLOCKED or NOT_RUN; a missing prerequisite is not SKIP-to-PASS. Keep evidence outside application/user state, hash the export and preserve failed attempts. Record resource use rather than declaring unmeasured minimum hardware requirements.

Cross-OS acceptance requires the same immutable candidate and its exact dependency pins to pass on both supported targets. If a pin is unavailable, record the incompatibility and prepare a new reviewed candidate; do not certify the original or reuse one OS result for the other. Installed dependency closure, first run, reboot, lifecycle, export and pilot results must bind to the same candidate bytes.

Cockroach R12 is a separate track. Require the audited pinned v26.2.5 engine and psycopg 3.3.5 with explicitly owned fresh disposable TLS database, roles and configuration. Run `tests/cockroach` independently with its own counts and artifacts; default Core regression and synthetic backends do not certify SQL. Without those offline inputs mark BLOCKED_ENVIRONMENT/NOT_RUN and make zero connections. No engine/driver download or existing/public database substitution is authorized here.

P1 requires actual independent clean OS installation/first run; P2 requires measured lifecycle/data rules; P3 additionally requires verified signed release trust, immutable digests/provenance/SBOM and update validation; D8 requires independent useful workflow acceptance. The current diagnostic candidate can prepare and demonstrate only part of P0 and unsigned offline integrity.
