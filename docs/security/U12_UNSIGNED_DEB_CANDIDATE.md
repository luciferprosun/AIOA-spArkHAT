# U12 / PKG-00+01 unsigned diagnostic .deb candidate

The candidate contains a versioned private application source payload, a thin isolated CPython 3.12 launcher, a terminal desktop entry and an explicitly inert offline arithmetic fixture. It delegates diagnostic and console modes to the existing runtime. It creates no owner/principal, backend, grant, signer or effect. Public console without an existing Core remains UNAVAILABLE. The supported launcher refuses all other commands.

P0/PKG-00 scope is LIMITED to this diagnostic payload. Its positive source allowlist includes required runtime and lab.archaioa Core code, approved Python/data/native sources and all three MIT notices. The unchanged secret scanner plus supplemental GitHub detector check every allowed input. Knowledge/PDF/media, archives, developer venv, user state, .env/Git, tests, baseline, the secret-looking critical_loop fixture, undeclared web_reader dependency and the library generator containing a developer home example are excluded. No third-party media or Python wheel is bundled; desktop entry uses a system theme icon. All packaged application code remains covered by the included root or nested MIT notice.

The build records the exact clean Git commit/tree, hashes, mode, size, source allowlist and license mapping, CycloneDX SBOM draft, ABI and recursively resolved installed distro dependency versions. CPython and its OS runtime dependencies are exact-version package dependencies rather than a copied development environment. Optional Non-Zero/Cockroach/google/Playwright/Textual and U06 execution modes are not part of this package's closure or supported launcher. Full application dependency/browser closure remains NOT_ACCEPTED.

Only the two fixed owned source paths `runtime/nonzero_cloudops/state/__init__.py` and `files.py` are exempted from the state-directory name exclusion because the existing Core imports its filesystem contracts there. Both are tracked, licensed, hashed and scanned like all payload inputs. Other state paths and user data remain denied, including `runtime/nonzero_cloudops/state/user.py`.

`python3 -B scripts/build_deb_candidate.py --output <disposable-evidence-directory>` performs BUILD only via dpkg-deb; no maintainer scripts, sudo, install, apt, download, system configuration, root daemon, autostart or production signer. Application files are archive-owned root:root with readable 0644 modes, directories 0755 and launcher 0755. Runtime does not write inside the private package path. User runtime state continues to use existing Core configuration; this diagnostic slice creates none.

Local verification inspects dpkg-deb -I/-c, checks extracted content/hashes/modes, tests the thin launcher in isolated mode with checkout/home hidden and hostile PYTHONPATH/current directory, checks no secrets or extra files, and compares two unsigned builds. Extraction is not OS installation. Existing wheel/sdist metadata remains unchanged and separate.

Target: Ubuntu 24.04/Mint 22.x x86-64 CPython 3.12 candidate only. P1 clean OS installation, matching managed browser, upgrade/uninstall, two-OS user acceptance, P2/P3 lifecycle/release integrity, U13, production signing and full desktop workflow remain NOT_ACCEPTED.
