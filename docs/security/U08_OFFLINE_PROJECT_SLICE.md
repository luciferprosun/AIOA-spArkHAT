# U08 controlled offline Python fixture

`PythonProjectPlan` is inert metadata with no authority. An operator supplies an
independent `ProjectSeed` and reviews the fixed worker, source bytes and expected
test value before registering a recipe. The recipe and all input/output hashes
are bound by the existing U06 registry, immutable operation, owner SessionGrant,
EffectWarrant, journal/outbox START and native readback/completion contracts.
Model proposals select a previously registered recipe only. They cannot add
paths, scripts, approval, dependencies, environment or commands.

This slice creates or replaces only `src/app.py` in a fresh private `/work/project`
inside the accepted U06 sandbox. Independent seed identity, revision and preimage
must match the plan. Pinned directory descriptors, no-follow opens, exclusive
creation, single-link regular-file checks, immutable preimages and replacement
readback protect the controlled fixture. Replacement uses a same-directory
temporary file and rename. This is a single-writer fixture, not concurrent CAS
for an existing host project. The target fingerprint/revision must be supplied
to the native Core target probe from this reviewed plan.

The fixture program is limited to one `value = expression` assignment with bounded
integer literals and addition, subtraction, multiplication or unary signs. A
shared AST validator in the inert builder and standalone worker refuses calls,
imports, control flow and test termination before project execution. Comments,
including injected approval claims, remain data. This deliberately narrow program
cannot skip the trusted test by exiting with code zero.

The fixed worker compiles the actual file and uses a fixed controlled test runner
from read-only `/inputs` using the curated Python runtime. Actual source and deterministic test
result artifacts, actual exit and independent U06 readback are required; model
DONE text is insufficient. This is a small arithmetic project fixture, not
proof of arbitrary program semantics. Interrupted or uncertain effects retain
UNKNOWN/liability and never grant a repair or repeated execution.

Historical provenance: Master v2 sections 10–12 / PC-05 as mapped by
`NEXT_ULTRA_MASTER_PROMPT.md`; local audited adapter commit
`5ec74f85256c260dadbc795143eb132b4119aab6` supplied workspace-confinement and inert
package-proposal concepts. Its lexical path guard is not reused as a security
boundary. The existing Core, PCAF, liability, warrants, CockroachDB ports, MCP
and Nebius structure remain the authority path.

Deferred scope: shared/persistent host projects, general Python programs, arbitrary build commands,
dependency acquisition/installation, system installation and automatic repair.
No new Core, production signing, network/provider call or remote publication.
