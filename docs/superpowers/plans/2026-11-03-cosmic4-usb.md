# Cosmic4 USB Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Dostarczyć prawdziwy APK4.0 i skonfigurować tę konkretną instalację Xiaomi bez usunięcia Cosmic0.3.0 lub jego danych.

**Architecture:** Dodatkowy wariant istniejącego klienta Compose i istniejący Core. USB przenosi publiczną konfigurację; istniejący ViewModel wykonuje istniejący protokół. Trwały osobny podpis APK, bez sekretów w APK.

**Tech Stack:** Kotlin2.2.21, Compose, AndroidSDK36/JDK17/Gradle8.13, Python, istniejący GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-03-cosmic4-usb-design.md`
