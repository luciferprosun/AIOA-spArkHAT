## Running the bounded synthetic smoke locally

Use **a clean, isolated scratch checkout** and a private temporary directory on the host's healthy *internal* disk:

~~~sh
python3 -B -m unittest discover -s experiments/nemotron48/tests -v
S="$(mktemp -d /var/tmp/n48-fixture.XXXXXXXX)"
chmod 700 "$S"
python3 -B -m experiments.nemotron48 init --state-dir "$S" --owner-scope private_researcher
python3 -B -m experiments.nemotron48 supervise --state-dir "$S" --max-items 3 --max-wall-seconds 120 --max-segments 50
python3 -B -m experiments.nemotron48 verify --state-dir "$S"
python3 -B -m experiments.nemotron48 audit --state-dir "$S"
~~~

A successful smoke must report FIXTURE, zero paid model calls, and NOT_PROVEN_48H. The smoke does not require running Nemotron.

## GitHub cannot by itself prove 48 hours of continuous work

Standard GitHub-hosted jobs stop at 6 hours. workflow_dispatch and scheduled events require the workflow file to exist on the default branch; we intentionally keep this experiment off main. Pushes generated by the built-in GITHUB_TOKEN do not recursively start new push workflows. Therefore **this branch-only Actions job cannot honestly conduct a continuous 48-hour LIVE mission**.

Future approved topology: GitHub = source control/CI/evidence index; a stable independently authorized worker or reviewed segmented scheduler = execution; durable storage with external integrity anchor = checkpoint data; Nebius Token Factory exact-model API = inference; validated SMTP emergency path = alerts. A segmented 48-hour campaign may measure elapsed time, but it is not evidence of continuous operation unless checkpoint gaps and work attestations pass a dedicated standard.

Do NOT substitute the 4 GB laptop or faulty LSC disk as always-on worker while GOLD72 runs. No new USB writes, no Tailscale/signer changes, no external cloud deployment or billing without separate human permission.
