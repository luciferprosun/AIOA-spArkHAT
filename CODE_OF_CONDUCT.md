# Code of Conduct

AIOA spArkHAT welcomes technical disagreement, critical review, security research, and evidence-based challenge.

Participants are expected to:

- communicate respectfully and focus criticism on ideas, code, evidence, and behavior;
- avoid harassment, threats, discrimination, doxxing, or targeted abuse;
- respect privacy, security boundaries, licenses, and responsible-disclosure practices;
- avoid knowingly misleading technical or research claims;
- disclose conflicts of interest when they materially affect project decisions;
- follow maintainer instructions during coordinated security response.

Unacceptable conduct may result in content removal, restricted participation, or removal from the project.

For ordinary project concerns, contact the maintainer through GitHub. For vulnerabilities or sensitive security matters, use the private process in [SECURITY.md](SECURITY.md).

Maintainers are responsible for applying this policy consistently and may document significant moderation decisions when doing so does not expose private or security-sensitive information.
